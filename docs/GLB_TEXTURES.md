# Исправление белых импортированных моделей

## Причина

Проверены исходные локальные GLB `tyrant_king_-_tyrannosaurus.glb` (53 421 052
байта, шесть встроенных изображений) и
`animated_3d_tyrannosaurus_rex_dinosaur_loop.glb` (15 942 168 байт, четыре
встроенных изображения). Оба используют `KHR_materials_pbrSpecularGlossiness`.
В первом файле цвет кожи задаёт `diffuseTexture`, а не `baseColorTexture`.
Современный GLTFLoader пропускал это старое расширение и оставлял белый цвет,
при этом продолжая загружать обычные normalTexture и occlusionTexture.
Из-за этого рельеф был виден, а окраска отсутствовала. На этапе упаковки
импорта цветовые карты уже не попадали в сохранённый GLB.

Удаление поддержки описано в [руководстве миграции Three.js, r146 → r147](https://github.com/mrdoob/three.js/wiki/Migration-Guide#146--147).

## Исправление

`src/model-loader.ts` добавляет адаптацию материала до чтения геометрии.
Цвет и прозрачность берутся из исходных diffuseFactor/diffuseTexture.
Specular RGB переносится в `KHR_materials_specular` с IOR=0 по
[описанию конверсии Khronos](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_specular/README.md#specular-glossiness-materials).
Сам Three.js заменяет этот IOR на 1000 для численной устойчивости. Альфа
specular-glossiness карты преобразуется в зелёный канал линейной карты
шероховатости: `roughness = 1 - glossinessFactor * alpha`. RGB отражения,
цветовое пространство sRGB, UV-канал, трансформации и режимы обёртки сохраняются.
Нормали и AO загружаются обычным путём. Материалы без старого расширения
используют прежний путь. Игнорируемые картой unlit-материала normal/AO
не считаются ошибкой.

Загрузчик проверяет обязательные карты использованных материалов. Если
изображение не загрузилось, импорт завершается сообщением об ошибке, а не
публикует белую модель. Сетевые ресурсы по-прежнему запрещены.

Самодостаточный GLB теперь сохраняется исходными байтами. Это сохраняет качество
изображений и не увеличивает файл из-за повторного PNG/JPEG-кодирования или
добавления производных карт. Нормализация сохраняется в необязательном поле
`ModelAsset.normalize` и применяется при загрузке. Прежние уже нормализованные
ресурсы без этого поля продолжают загружаться без изменения размера.
Ключ кэша учитывает нормализацию. Размерные лимиты не изменены.

Для glTF с внешними ресурсами остаётся упаковка через GLTFExporter.
Для исходного GLB со старым материалом адаптация выполняется при каждом первом
чтении ресурса; подготовленные модели затем переиспользуются из кэша.

## Уже расставленные модели

В «Объекты → Библиотека моделей» выберите импортированную модель и нажмите
«Заменить выбранную модель из файла». Выберите её исходный GLB.
Заменяется ресурс с сохранением ID: существующие экземпляры, трансформации,
группы и настройки анимации сохраняются. Замена участвует в отмене/повторе.
Лимит 20 моделей проверяется с учётом замены, а не добавления 21-й модели.
Если новый файл не подходит или клипы не соответствуют экземплярам, текущий
мир сохраняется. Исходные файлы из Downloads не изменяются.

Автоматически восстановить ранее отброшенную цветовую карту из старого
переупакованного ресурса нельзя: нужен исходный GLB.

## Проверка

`tests/model-textures.test.ts` проверяет факторы старого материала, преобразование
альфа-канала в шероховатость, ошибку отсутствующей карты, корректность unlit,
замену при лимите 20 ресурсов, сохранение экземпляров и отмену/повтор.
Тест скелетного импорта дополнительно проверяет побайтовое сохранение исходного
GLB и корректную деформацию после внешней нормализации.

Интерактивная проверка — `/verification/texture.html`, отдельная IndexedDB
`terrain-editor-texture-check`. Пользовательские GLB для проверки временно
помещаются в `verification/texture-input/`; они исключены из Git и не включаются
в автономный редактор. Исходные модели принадлежат их авторам и не добавлены
в библиотеку встроенных моделей.

Результат проверки: 280 тестов пройдены; strict TypeScript и обычная/автономная
сборки завершились успешно. В Chrome у обеих реальных моделей восстановлены
цвет, normal map и карты отражения/шероховатости. Цветовая карта тела статического
динозавра — 4096×4096, второго материала — 1024×1024; у анимированного — 2048×2048.
Оба проекта сохранены и повторно открыты с текстурами. Размеры исходных GLB
сохранились без увеличения. Ошибок JavaScript и шейдеров нет.
Запись и снимки: `verification/textures/`.
