# Индивидуальная форма растений

В `terragen_v.0.2.1` встроенные деревья, кустарники и почвенная растительность
получают индивидуальные изгибы ствола, поворот ветвей, асимметрию и неровные
очертания кроны. Это работает в обычных лесах, джунглях и тайге, включая
вручную добавленные растения. Существующие миры получают вариации при открытии;
перегенерировать мир и менять расстановку не требуется.

Форма воспроизводимо вычисляется из вида и ID экземпляра. Перемещение,
поворот, сохранение, загрузка и отмена сохраняют форму. Копия получает новый
ID и собственную вариацию. Мелкие растения на земле используют сид расстановки,
вид и постоянные координаты точки; движение камеры не меняет их форму.

Размеры, оттенки, погода и сезоны продолжают дополнять разнообразие.
Корни закреплены у основания, а ветер накладывается на индивидуальную форму.
Исходная топология ветвления каждого вида сохраняется: эта версия изменяет
положение и пропорции существующих ветвей и кроны. Генерация нового числа
ветвей и полноценная симуляция роста остаются отдельным развитием системы.

## Производительность и согласованность

- На каждый вид и LOD вычисляются шесть общих геометрических форм. Экземпляры
  получают индивидуальные веса смешивания в `InstancedMesh.morphTexture`.
  Геометрия общая; дополнительный объект или пакет отрисовки для каждого
  дерева не создаётся. Число треугольников остаётся прежним.
- Обработка вершин требует дополнительных операций и памяти для общих
  морф-форм. Профили качества и дистанционные LOD продолжают действовать.
- Одни и те же параметры применяются ко всем частям растения и LOD.
  Деформация ограничена исходными габаритами, поэтому не ломает отступы
  от троп и соседних объектов.
- Тени используют те же морф-формы и ветер. Выбор мышью и VR-лучом
  проверяет фактически деформированную поверхность. Рамка выделения
  учитывает индивидуальную форму.
- Для деревьев сохраняется одна коллизия ствола на экземпляр — выпуклая
  оболочка вдоль изгиба. Листва остаётся проходимой.
- Импортированные GLB, анимированные модели, камни, постройки и брёвна
  сохраняют авторскую геометрию. Новый механизм применяется к встроенным
  живым растениям, а не к произвольной пользовательской модели.

Новые поля формата проекта не требуются: версия алгоритма `plant-v1`
и существующие идентификаторы воспроизводят те же формы при переносе проекта.
OBJ экспортирует рельеф; перенос мира с растительностью выполняется через
обычный файл проекта.

Проверки: `npm test`, `npm run typecheck`, `npm run build`.
`verification/plant-variation-check.ts` сравнивает реальную отрисовку GPU
с запечённой на CPU геометрией, включая тени и ветер, для нескольких биомов.
