# PICO 4 Ultra: VR через ПК

Ветка `terragen_v.0.2.0` добавляет WebXR VR в существующий редактор. Мир
отрисовывается видеокартой ноутбука; PICO Connect передаёт изображение в шлем
и возвращает отслеживание головы и контроллеров. Отдельный APK не требуется.

## Первый запуск

1. В PyCharm переключитесь на `terragen_v.0.2.0` и выполните Update Project.
   Если зависимости уже установлены и `package-lock.json` не менялся,
   повторять `npm ci` не требуется. Запустите `npm run dev`.
2. Установите актуальные PICO Connect на ПК и в шлеме, а также SteamVR на ПК.
   Обновите драйвер NVIDIA. На ноутбуке выберите для браузера дискретную
   RTX 2050: Windows → Параметры → Система → Дисплей → Графика → браузер →
   «Высокая производительность». Подключите питание ноутбука.
3. Подключите PICO к ПК в PICO Connect. Для первого теста предпочтителен
   USB 3; также возможна беспроводная передача при подходящей локальной сети.
   Запустите SteamVR и убедитесь, что он видит шлем и два контроллера.
4. В SteamVR откройте Настройки → OpenXR → назначьте SteamVR активной средой
   OpenXR. В некоторых версиях пункт находится в настройках разработчика.
   Название и расположение зависят от версии SteamVR.
5. В актуальном Chrome или Edge **на ПК** откройте адрес, который показал
   `npm run dev` (обычно `http://127.0.0.1:5173/`). Откройте или создайте мир.
   Обычная трансляция рабочего стола PICO Connect ещё не означает запуск VR.
6. Нажмите «Войти в VR» в верхней панели и разрешите браузеру доступ к шлему.
   Если кнопка неактивна, откройте Настройки → Камера и прогулка →
   «PICO · VR через ПК» → «Проверить подключение VR».
   Там показывается результат проверки WebXR.

Поддержка PC WebXR зависит от сочетания браузера, OpenXR runtime и драйверов.
Критерий готовности — успешная проверка `immersive-vr`, а затем вход в сессию.
Если браузер не предоставляет WebXR либо не видит активный runtime,
редактор покажет причину. Специальные экспериментальные флаги не включаются
автоматически. Автономный браузер шлема — отдельный путь подключения;
для этого режима он не нужен.

## Управление

| Контроллер | Действие |
| --- | --- |
| Левый стик | Ходьба в направлении взгляда; наклон стика задаёт скорость |
| Правый стик влево / вправо | Поворот на 30°; перед следующим поворотом вернуть стик в центр |
| Левый курок, удерживать | Показать дугу телепортации |
| Отпустить левый курок | Переместиться к зелёному кольцу; оранжевая дуга означает запрет |
| Правый курок | Выбрать объект лучом или нажать кнопку пространственного меню |
| A | Прыжок; в полёте — подъём при удержании |
| B | Включить / выключить полёт |
| Y, удерживать | Снижение в полёте |
| X | Открыть / закрыть меню, приостановив перемещение |
| Правый Grip, удерживать | Перенос отдельной вручную добавленной модели |
| Отпустить правый Grip | Применить положение и поворот, показанные рамкой |

Меню содержит продолжение, полёт, «Сохранить сейчас», отмену последнего
изменения и выход. Перенос поддерживает историю проекта: отменить его можно
в меню VR или через Ctrl+Z после выхода. Рассеянная растительность, группы
и плавучие модели выбираются, но не переносятся контроллером. Анимационные
механизмы, открывание дверей, физическое бросание предметов и управление
воздушным шаром в эту версию VR не входят.

Вращение головы и высоту глаз задаёт шлем, без искусственного покачивания
камеры. Коллизии работают для ходьбы, полёта и горизонтальных шагов
пользователя в игровой зоне. Для телепортации проверяются уклон,
границы карты, уровень воды и место для тела под потолком. Используются
выбранные коллизии моделей: для корабля нужна «Точная геометрия».
Габариты тела пока берутся из настроек прогулки; приседание головы не
уменьшает коллизионную капсулу. При потере видимости XR-сеанса перемещение
приостанавливается; продолжите через X / меню после возвращения.

Выход из VR восстанавливает положение и режим камеры до входа. Изменения
объектов сохраняются в текущем проекте; в «Мои миры» мир попадает после
явного «Сохранить сейчас», как и в обычном режиме.

## RTX 2050

VR автоматически использует экономный профиль, масштаб XR-буфера 65%,
максимальную доступную фиксированную фовеацию и отключает прямые тени.
Выбранное качество обычного редактора не перезаписывается и восстанавливается
после выхода. Параметры разрешения SteamVR дополнительно влияют на нагрузку.
Для первого теста оставьте 100% или уменьшите его при необходимости.

Волны и водопады сохраняются. Дополнительные захваты отражения и экранного
преломления в VR отключены. Под водой используется пространственный туман
вместо обычного одноглазого экранного постэффекта.

Сначала проверьте небольшой мир с умеренной растительностью. Увеличивайте
плотность леса и сложность GLB после проверки плавности. Автоматический
профиль не гарантирует заданную частоту для произвольно тяжёлого мира.

## Разработка и проверки

После Update Project dev-сервер подхватывает изменения. При изменениях камеры
или VR-управления выйдите из VR, дождитесь перезагрузки страницы и войдите
снова. Для VR используйте dev-сервер или HTTP(S)-сервер сборки;
запуск standalone-файла через `file://` не является поддерживаемым способом.

Автотесты: `npm test`, `npm run typecheck`, `npm run build`.
Проверяются аналоговое движение, мёртвая зона стика, дискретные повороты,
телепортация на импортированную палубу, препятствия и восстановление
настроек. Браузерная проверка с эмулятором WebXR дополняет их, но качество
передачи PICO Connect, задержку и производительность на RTX 2050 требуется
оценить на реальном ноутбуке и шлеме.
